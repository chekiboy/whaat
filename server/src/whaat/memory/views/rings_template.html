Memória-gyűrűk

Az identitás memóriája szintekbe rendezve: középen a mag (a core), körülötte a témák, vagyis a memória-mappák rétegek szerint (személyes, globális, projekt, repó), a témákban a kártyák. Kattints egy témára a kinyitásához, egy kártyára a részletekért. A „Mikor” chipek megmutatják, mit tenne eléd egy hook az adott pillanatban.
